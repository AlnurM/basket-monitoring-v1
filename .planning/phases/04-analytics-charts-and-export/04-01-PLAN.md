2. Extend PriceHistoryRepository in price_history.py with these new methods:

**get_price_range(basket_item_ids, start_date, end_date)** -> list[PriceHistory]:
- SELECT all PriceHistory records WHERE basket_item_id IN (ids) AND scraped_at >= start_date AND scraped_at <= end_date ORDER BY scraped_at ASC.
- Used by charts and export.

**get_first_prices_in_range(basket_item_ids, start_date)** -> dict[int, tuple[Decimal | None, bool]]:
- Use DISTINCT ON (basket_item_id) with ORDER BY basket_item_id, scraped_at ASC to get the EARLIEST price record for each item after start_date.
- Returns dict mapping basket_item_id to (price, is_available).
- Same pattern as existing get_previous_prices but ASC order instead of DESC.

**get_daily_basket_totals(basket_item_ids, quantities: dict[int, int], start_date, end_date)** -> list[tuple[date, Decimal]]:
- For charting: get daily basket total (sum of latest-price-per-item-per-day * quantity).
- Implementation approach:
  - Subquery: for each (basket_item_id, date), get the latest price using DISTINCT ON ordered by scraped_at DESC, cast scraped_at to date.
  - Main query: GROUP BY date, SUM(price * quantity) using a CASE expression or Python-side multiplication.
  - Alternative simpler approach: fetch all records in range with get_price_range, then aggregate in Python (group by date, pick last price per item per day, multiply by quantity, sum).
  - Use the Python-side approach for clarity since data volume is manageable (90 days max * 50 items = 4500 records max).
- Returns list of (date, total) tuples sorted by date.

**get_export_data(basket_item_ids, start_date, end_date)** -> list[PriceHistory]:
- Same as get_price_range but eagerly loads the basket_item relationship (for product name and quantity).
- Use selectinload(PriceHistory.basket_item) to avoid N+1.

Add necessary imports: `datetime`, `from sqlalchemy.orm import selectinload` (for get_export_data).
