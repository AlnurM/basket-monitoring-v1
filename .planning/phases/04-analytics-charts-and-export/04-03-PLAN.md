Follow the exact handler pattern from scrape.py. Create a Router named "analytics".

1. `/changes [N]` handler (per D-01, ANLT-01):
   ```python
   @router.message(Command("changes"))
   async def cmd_changes(message, session, user, lang, **kwargs):
   ```
   - Check user exists (same guard as scrape.py).
   - Parse optional days argument from message.text.split(). Default 7. Clamp to 1-90.
   - If arg is not a valid int, reply with get_text("changes_invalid_days", lang).
   - Call `generate_changes_report(session, user.id, days, lang)`.
   - If None, reply get_text("changes_no_data", lang).
   - Otherwise split_message and send parts.

2. `/compare` handler (per D-03, ANLT-03):
   ```python
   @router.message(Command("compare"))
   async def cmd_compare(message, session, user, lang, **kwargs):
   ```
   - Check user exists.
   - Call `generate_comparison_report(session, user.id, lang)`.
   - If None, reply get_text("compare_no_data", lang).
   - split_message and send parts.

3. `/chart [days]` handler (per D-07, D-09, CHRT-01):
   ```python
   @router.message(Command("chart"))
   async def cmd_chart(message, session, user, lang, **kwargs):
   ```
   - Check user exists.
   - Get active basket.
   - Parse optional days argument. Default 30. Clamp 7-90.
   - Send "generating..." message.
   - Call `generate_basket_chart(session, basket.id, basket.name, days, lang)`.
   - If None, reply with no_data message.
   - Otherwise send as photo: `BufferedInputFile(chart_bytes, filename="chart.png")` via `message.answer_photo(photo=photo)`.

4. `/chart_item [index] [days]` handler (per D-08, D-09, CHRT-02):
   ```python
   @router.message(Command("chart_item"))
   async def cmd_chart_item(message, session, user, lang, **kwargs):
   ```
   - Check user exists.
   - Get active basket.
   - Parse args: first arg is item index (required, 1-based), second is days (optional, default 30).
   - If no item index, reply with usage message.
   - Call `generate_item_chart(session, basket.id, item_index, days, lang)`.
   - If returns (None, error_msg), reply with error_msg.
   - Otherwise send as photo.

5. `/export` handler (per D-14, EXPT-01):
   ```python
   @router.message(Command("export"))
   async def cmd_export(message, session, user, lang, **kwargs):
   ```
   - Check user exists.
   - Get active basket.
   - Call `generate_export(session, basket.id, basket.name, basket.source, lang)`.
   - If None, reply no_data.
   - Otherwise send as document: `BufferedInputFile(csv_bytes, filename=f"{basket.name}_prices.csv")` via `message.answer_document(document=doc)`.
