Create `src/price_spy/bot/handlers/product.py` with `Router(name="product")`.

**Helper function -- `parse_product_lines(text: str) -> list[tuple[str, int]]`:**
Parse message text into list of (url, quantity) tuples per D-04 format. For each non-empty line:
- Split from right to separate URL from optional quantity: `parts = line.rsplit(None, 1)`
- If 2 parts and second part is a positive integer, use it as quantity
- Otherwise entire line is the URL, quantity = 1
- Return list of (url, qty) tuples

**Helper function -- `validate_url_for_basket(url: str, basket_source: str) -> str | None`:**
Returns i18n error key or None if valid. Per D-05:
- Call `detect_source(url)` from `services/scraper.py`
- If source is None, return `"error_invalid_url"`
- If `SOURCE_TO_BASKET[source] != basket_source`, return `"error_source_mismatch"`
- Return None (valid)

**Handlers (registration order matters -- FSM state handler first per Pitfall 5):**

1. **`callback_add_item_prompt`** -- `@router.callback_query(BasketActionCB.filter(F.action == "add"))`
   - Get basket_id from callback_data
   - Check item limit: `BasketItemRepository(session).count_by_basket(basket_id) >= settings.max_items_per_basket`
   - If limit reached, send error via `callback.message.answer(get_text("error_item_limit_reached", lang, max=settings.max_items_per_basket))`
   - Otherwise: set FSM state `AddProduct.waiting_for_urls`, store basket_id in FSM data: `await state.update_data(basket_id=basket_id)`
   - Send prompt: `callback.message.answer(get_text("send_urls_prompt", lang))`
   - `await callback.answer()`

2. **`receive_product_urls`** -- `@router.message(AddProduct.waiting_for_urls)`
   - Get basket_id from FSM data: `data = await state.get_data(); basket_id = data["basket_id"]`
   - Clear FSM state: `await state.clear()`
   - Parse URLs: `lines = parse_product_lines(message.text)`
   - Get basket: `basket = await BasketRepository(session).get_by_id(basket_id)`
   - If basket is None (deleted between prompt and input), send error and return
   - Send "Adding products..." message: `status_msg = await message.answer(get_text("adding_products", lang))`
   - For each (url, qty) in lines:
     a. Validate: `error_key = validate_url_for_basket(url, basket.source)`
     b. If error_key, collect error message with details (per D-10): use `get_text(error_key, lang, source=source_name, basket=basket.name, basket_source=basket.source)` for source_mismatch, or `get_text(error_key, lang)` for invalid_url
     c. If valid: check item limit, extract product_id via `extract_product_id(url, source)`, check for duplicate (catch IntegrityError or pre-check)
     d. Create BasketItem via `BasketItemRepository(session).create(basket_id, url, product_id, source, None, qty)`
   - After all items created, trigger first scrape per D-06:
     a. Collect URLs of successfully added items
     b. Create `ScraperService(session)` and call `await scraper.scrape_urls(urls)`
     c. For each ScrapeResult:
        - If `result.ok`: update item name via `item_repo.update_name(item_id, result.data.name)`, create price history record via `PriceHistoryRepository(session).create(item_id, Decimal(result.data.price) if result.data.price else None, Decimal(result.data.original_price) if result.data.original_price else None, result.data.is_available)` per HIST-01, HIST-02
        - Build confirmation line: `get_text("product_added", lang, name=result.data.name, qty=qty, price=result.data.price)` or `product_added_no_price` if price is None
        - If `result.error`: build error line: `get_text("product_add_failed", lang, url=url, reason=result.error)`
   - Edit status_msg with all results (concatenate confirmation + error lines)
   - Convert int prices to Decimal when storing: `from decimal import Decimal; Decimal(str(price))` -- PriceResult.price is int (tenge), PriceHistory.price is Numeric(12,2)

3. **`handle_url_message`** -- `@router.message(F.text.regexp(r"https?://"))`
   - This catches URL messages sent when NOT in AddProduct FSM state (user just pastes a URL without tapping Add button)
   - Get active basket: `basket = await BasketRepository(session).get_active_basket(user.id)`
   - If no active basket: send `get_text("error_no_active_basket", lang)` and return
   - Process SAME logic as receive_product_urls but using active basket instead of FSM basket_id
   - This implements D-04: "Bot detects URLs in any message sent while a basket is active"

   NOTE: To avoid code duplication, extract the URL processing logic into a private async function `_process_urls(message, session, user, lang, basket, text)` and call it from both handlers 2 and 3.

4. **`callback_list_items`** -- `@router.callback_query(BasketActionCB.filter(F.action == "items"))`
   - Get basket from repo by callback_data.basket_id
   - Get items with prices: `BasketItemRepository(session).get_basket_items_with_latest_price(basket_id)`
   - If empty, show `get_text("items_empty", lang)`
   - Otherwise build text per D-07, D-08, D-09:
     - For each item: numbered line showing name, quantity, unit price, line total
     - If item has original_price != price (discount): use `item_line_discount` template with strikethrough original price per D-08
     - If is_available is False: use `item_line_unavailable` template with red marker per D-08
     - At bottom: `get_text("basket_total", lang, total=sum_of_all_line_totals)`
   - Show paginated if >10 items using `items_page_keyboard` from keyboards/pagination.py
   - For first page (page=0), edit callback message with text + keyboard
   - `await callback.answer()`

5. **`callback_prices`** -- `@router.callback_query(BasketActionCB.filter(F.action == "prices"))`
   - Same display as callback_list_items (D-07 says list items shows prices). Can delegate to same display function.
   - `await callback.answer()`

6. **`callback_page`** -- `@router.callback_query(ItemCB.filter(F.action == "page"))`
   - Get page number from callback_data.page
   - Rebuild items display for that page (same logic as callback_list_items but offset by page*10)
   - Edit message with updated text + pagination keyboard
   - `await callback.answer()`

7. **`callback_remove_item`** -- `@router.callback_query(ItemCB.filter(F.action == "remove"))` (per PROD-07)
   - Get item from `BasketItemRepository(session).get_by_id(callback_data.item_id)`
   - Show confirmation: `get_text("confirm_remove_item", lang, name=item.name or "Unknown")`
   - Use `confirm_remove_item_keyboard(callback_data.basket_id, callback_data.item_id, lang)` from keyboards/basket.py for the Yes/No confirmation buttons
   - `await callback.answer()`

8. **`callback_confirm_remove`** -- `@router.callback_query(ItemCB.filter(F.action == "confirm_remove"))` (per PROD-07)
   - Get item, delete via `item_repo.delete(callback_data.item_id)` (CASCADE deletes price history)
   - Edit message: `get_text("item_removed", lang, name=item.name or "Unknown")`
   - `await callback.answer()`

async def cleanup_old_prices() -> None:
